# **Занятие № 7**

1. Понятие «квадратичный вычет по модулю n». Расскажите о символе Лежандра. Число a ∈ [0, n−1] называется квадратичным вычетом по модулю n, если существует x такое, что x² ≡ a (mod n); иначе — квадратичный невычет. Ровно половина элементов интервала является вычетами. Символ Лежандра (a/p) равен 1, если a — квадратичный вычет по простому модулю p; −1, если невычет; 0, если p | a.
2. Как вычислить символ Лежандра по формуле Эйлера? По закону квадратичной взаимности Гаусса? Сформулируйте закон квадратичной взаимности. По формуле Эйлера: (a/p) = a^((p−1)/2) mod p. По закону квадратичной взаимности Гаусса: $(q/p) = (p/q) · (−1)^((p−1)(q−1)/4)$, то есть $(q/p) = −(p/q)$, если $p ≡ q ≡ 3 (mod 4)$, и (q/p) = (p/q) иначе. Закон квадратичной взаимности связывает символы Лежандра для взаимно простых нечётных простых чисел и позволяет быстро вычислять символ без возведения в большие степени.
3. Расскажите о тестах простоты Миллера–Рабина и Соловея–Штрассена. Тест Миллера–Рабина — вероятностный тест, основанный на критерии непростоты: нечётное n ≥ 3 составное тогда и только тогда, когда n — полный квадрат либо найдутся x, y такие, что x ≠ ±y (mod n) и x² ≡ y² (mod n). Тест ищет свидетеля непростоты среди случайных a. Тест Соловея–Штрассена опирается на малую теорему Ферма и свойства символа Якоби: проверяется сравнение a^((n−1)/2) ≡ (a/n) (mod n). Оба теста вероятностные, с каждой итерацией вероятность ошибки уменьшается.
4. Что представляет собой критерий непростоты числа, на котором основан вероятностный тест простоты Миллера–Рабина? Опишите алгоритм этого теста. Критерий: нечётное n ≥ 3 составное тогда и только тогда, когда n — полный квадрат или найдутся x ≠ ±y (mod n) с x² ≡ y² (mod n). Алгоритм: n − 1 = 2^s · d, где d нечётно. Для каждого a от 2 до r + 1: вычисляют x₀ = a^d mod n; если x₀ ∈ {1, n−1}, a — свидетель простоты; иначе проверяют, содержится ли n − 1 в последовательности xᵢ₊₁ = xᵢ² mod n. Если нет — a свидетель непростоты, n составное. После r свидетелей простоты — «n вероятно простое».
5. Какое число называется свидетелем простоты? Свидетелем непростоты? Свидетель простоты — число a, для которого выполнено одно из условий: a^d ≡ ±1 (mod n) или существует k (0 < k < s) с a^(2^k·d) ≡ −1 (mod n). Свидетель непростоты — число a, для которого ни одно из этих условий не выполнено; его наличие доказывает, что n составное.
6. Как работает вероятностный тест простоты Соловея–Штрассена, основанный на малой теореме Ферма и свойствах символа Якоби? Опишите его алгоритм. Выбирается k ≥ 1. В каждом раунде случайно выбирается a < n и вычисляется d = НОД(a, n). Если d > 1 — n составное. Иначе проверяется сравнение a^((n−1)/2) ≡ (a/n) (mod n); если не выполнено — n составное, иначе a — свидетель простоты. После k раундов со свидетелями простоты делается вывод «n вероятно простое». Вероятность ошибки меньше 2^(−k). Тест отсеивает числа Кармайкла, но уступает Миллеру–Рабину по точности.
7. Что представляют собой числа Кармайкла? Приведите примеры этих чисел. Составные числа n, для которых малая теорема Ферма выполняется для всех a, взаимно простых с n: $a^(n−1) ≡ 1$ (mod n). Примеры: $561 = 3·11·17, 1105 = 5·13·17, 1729 = 7·13·19, 2465 = 5·17·29, 2821 = 7·13·31$.
8. Полиномиальный тест простоты AKS. Квадратный корень в конечных полях. Тест AKS — детерминированный полиномиальный тест простоты, разработанный Агравелой, Каялом и Саксеной в 2004 г. Извлечение квадратного корня в конечных полях выполняется алгоритмом Шенкса–Тоннелли: для p ≡ 3 (mod 4) корень равен a^((p+1)/4); для p ≡ 1 (mod 4) используется итеративная процедура с квадратичным невычетом.
9. Сформулируйте теорему индийских математиков Агравелы, Каялы и Саксены, на которой основан тест AKS проверки простоты заданного числа. Пусть n — нечётное натуральное число, r — простое, и выполнены условия: (1) n не делится ни на одно число ≤ r; (2) порядок n в мультипликативной группе Z*r не меньше (log₂n)²; (3) для всех a, 0 ≤ a ≤ r, выполнено (X + a)^n ≡ X^n + a в кольце Zₙ[X]/((X^r − 1)/(X − 1)). Тогда n простое.
10. Расскажите об алгоритме Шенкса и Тонелли извлечения квадратного корня в конечных полях. Как он работает в методе решета числового поля? Для p − 1 = 2^r · s (s нечётно) и квадратичного вычета a: при p ≡ 3 (mod 4) корень x = a^((p+1)/4); при p ≡ 1 (mod 4) строят последовательность пар (λᵢ, wᵢ) с wᵢ² ≡ a·λᵢ (mod p), пока λᵢ не станет равным 1; тогда x = wᵢ. В методе решета числового поля алгоритм используется для извлечения квадратных корней при построении линейных зависимостей.
11. Охарактеризуйте китайскую теорему об остатках и алгоритм Гарнера. Если m₁, ..., mₙ попарно взаимно просты, то для любых остатков rᵢ (0 ≤ rᵢ < mᵢ) найдётся x, дающий остаток rᵢ при делении на mᵢ, причём все такие x сравнимы по модулю m = m₁·...·mₙ. Алгоритм Гарнера вычисляет x последовательно: y₁ = x₁ = r₁; yᵢ₊₁ = (rᵢ₊₁ − xᵢ)/(m₁·...·mᵢ) mod mᵢ₊₁; xᵢ₊₁ = xᵢ + yᵢ₊₁·m₁·...·mᵢ. Достоинство — использование только одного предыдущего значения, что позволяет последовательно уточнять корень.

# **Краткое описание статьи: «Кибербезопасность в эпоху постквантовой криптографии»**

## Угрозы квантовой эпохи

Алгоритм Шора позволяет факторизовать большие числа и решать задачу дискретного логарифмирования за полиномиальное время, делая уязвимыми RSA, Diffie-Hellman и ECC. Для факторизации 2048-битного числа классическому компьютеру потребовались бы миллиарды лет, а квантовому — часы. Алгоритм Гровера даёт квадратичное ускорение поиска, снижая стойкость симметричных шифров; для сохранения безопасности длину ключей AES нужно удвоить (с 128 до 256 бит).

## Проблемы переходного периода

Переход к постквантовой криптографии сопряжён с вызовами: совместимость с существующими протоколами (TLS, SSH) требует обновления программного и аппаратного обеспечения; постквантовые алгоритмы требуют больше вычислительных ресурсов, что критично для IoT-устройств; стандартизация NIST начата в 2016 году, первые кандидаты выбраны в 2022-м, но полное тестирование займёт годы; необходима подготовка специалистов.

## Блокчейн и его криптографические основы

Блокчейн — распределённая база данных в виде цепочки блоков, каждый из которых содержит данные, хэш предыдущего блока и метаданные. Неизменяемость обеспечивается хэш-функциями (SHA-256). Консенсус достигается через Proof-of-Work, Proof-of-Stake или DPoS. Безопасность основана на цифровых подписях (ECDSA в Bitcoin и Ethereum), хэш-функциях и консенсусных механизмах. Однако ECDSA уязвим для квантовых атак: алгоритм Шора позволяет восстановить закрытый ключ из открытого. Блокчейн предоставляет уникальные возможности для защиты данных благодаря децентрализации, прозрачности и устойчивости к атакам Sybil и 51%.

## Постквантовая криптография

NIST выделяет несколько классов постквантовых алгоритмов: решётчатая криптография (CRYSTALS-Kyber для шифрования, CRYSTALS-Dilithium для подписей), криптография на кодах (алгоритм МакЭлиса), на хэш-функциях (XMSS, SPHINCS+), на многочленах (Rainbow), на суперсингулярных эллиптических кривых (SIKE). Подходы различаются по производительности, размерам ключей и вычислительной сложности. Для защиты блокчейн-систем предлагаются: замена ECDSA на постквантовые подписи (XMSS, SPHINCS+), квантово-устойчивые хэш-функции на основе SHA-3, гибридные схемы (ECDSA совместно с CRYSTALS-Dilithium).

## Заключение

Эпоха постквантовой криптографии представляет серьёзный вызов для кибербезопасности. Блокчейн благодаря децентрализации и криптографической основе может стать ключевым инструментом защиты данных, но требует адаптации к квантовым угрозам. Интеграция постквантовых алгоритмов, стандартизация, тестирование и обучение специалистов позволят обеспечить устойчивость к атакам будущего. Дальнейшие исследования должны быть направлены на оптимизацию PQC для распределённых систем и разработку стратегий миграции.
