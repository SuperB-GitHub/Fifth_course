# Доклад: Функция Эйлера и алгоритм RSA



# 3. Малая теорема Ферма как частный случай теоремы Лагранжа

## Формулировка малой теоремы Ферма

Если p — простое число, то для любого натурального a, не сравнимого с p, выполняется сравнение:

$a^(p−1) ≡ 1 (mod p)$

## Доказательство через теорему Лагранжа

Теорема Лагранжа утверждает: порядок любого элемента конечной группы является делителем порядка группы.

При простом p множество ненулевых элементов кольца Zp образует группу по умножению, имеющую p−1 элемент. Обозначим её Zp*. Порядок этой группы равен $p−1.$

Пусть a — произвольный элемент Zp*. По теореме Лагранжа порядок элемента a (наименьшее k такое, что $a^k ≡ 1$) является делителем порядка группы $p−1.$ Значит, существует целое m такое, что $p−1 = k·m.$

Тогда $a^(p−1) = a^(k·m) = (a^k)^m ≡ 1^m ≡ 1 (mod p).$

Теорема доказана.

# 4. Функция Эйлера φ(n)

Функция Эйлера φ(n) определяется как количество натуральных чисел, меньших n и взаимно простых с n. Иными словами, это число элементов в интервале от 1 до n−1, наибольший общий делитель которых с n равен единице.

Функция Эйлера обладает рядом полезных свойств, позволяющих вычислять её для различных чисел. Для простого p и натурального k справедлива формула $φ(p^k) = p^k − p^(k−1).$ 

В частности, для произведения двух простых чисел p и q выполняется равенство $φ(p · q) = (p − 1)(q − 1)$, которое и используется в алгоритме RSA.

# 5. Алгоритм RSA

Алгоритм RSA состоит из трёх частей: генерация ключей, шифрование и расшифрование.

### Генерация ключей

Сначала выбираются два произвольных простых числа p и q. Вычисляется их произведение n = p · q, которое служит модулем для всех дальнейших операций, и функция Эйлера φ(n) = (p − 1)(q − 1). Затем выбирается случайное число e, удовлетворяющее условиям 2 ≤ e < n и Н.О.Д.(φ(n), e) = 1, то есть взаимно простое с φ(n). Число e объявляется открытым ключом. Далее вычисляется элемент d, обратный к e по модулю φ(n): он должен удовлетворять условию e · d mod φ(n) = 1. Для вычисления d используется расширенный алгоритм Евклида, позволяющий решить уравнение e·d + φ(n)·y = 1. Число d объявляется закрытым ключом.

### Шифрование

Для шифрования текстовой строки M необходимо разбить её на отдельные символы, заменить каждый символ его числовым кодом (например, в кодировке Win-1251) и зашифровать каждый код c по формуле h = c^e mod n. Полученная последовательность шифрокодов h и представляет собой шифротекст.

### Расшифрование

Для восстановления исходного сообщения каждый шифрокод h заменяется на код c по формуле c = h^d mod n, после чего коды преобразуются обратно в символы текста. В примере выше c = 5^23 mod 55 = 15, что совпадает с исходным сообщением.

Корректность операции восстановления обеспечивается теоремой Эйлера: поскольку e·d ≡ 1 (mod φ(n)), показатель степени при возведении h в степень d даёт $c^(e·d) = c^(k·φ(n)+1) = c · (c^φ(n))^k = c.$ Таким образом, исходное сообщение восстанавливается однозначно.

# Обзор статьи: RSA в сравнительном анализе криптоалгоритмов

## Введение

В статье В.В. Ретивых и соавторов (2025) проведён сравнительный анализ AES, DES, RSA и ECC. RSA — первая практическая криптосистема с открытым ключом, представленная в 1977 году Ривестом, Шамиром и Адлеманом. Её стойкость основана на сложности факторизации больших целых чисел.

## Классические атаки на RSA

Наилучший классический алгоритм факторизации — общее решето числового поля (GNFS). Для RSA-2048 это примерно 2¹¹⁰ операций. В статье приведены реальные атаки: 

FREAK (принудительный переход на слабые export-grade ключи 40–512 бит), 

DROWN (кросс-протокольная атака на TLS через SSLv2), 

ROCA (уязвимость генерации ключей в чипах Infineon, CVE-2017-15361), 

ROBOT (padding-oracle для RSA PKCS#1 v1.5 в TLS).

## Квантовые атаки

Алгоритм Шора решает задачу факторизации за полиномиальное время: для RSA требуется O((log n)³) квантовых операций. Это ставит под угрозу все асимметричные системы, основанные на факторизации и дискретном логарифмировании. Гибридные атаки сочетают квантовый и классический криптоанализ.

## Меры защиты

Рекомендуется использовать ключи RSA от 3072 бит. В 2025 году квантовых компьютеров, достаточных для взлома RSA-2048 (10–20 тысяч кубитов), ещё нет, но демонстрационные атаки на упрощённые системы уже проводятся. Основное направление — переход на постквантовую криптографию, стандартизированную NIST: CRYSTALS-Kyber и CRYSTALS-Dilithium. Рекомендуются гибридные схемы, сочетающие классические и квантово-безопасные алгоритмы. 

## Заключение

RSA обеспечивает высокий уровень защиты от классических атак при корректной реализации и рекомендованных длинах ключей. Однако появление полноценных квантовых компьютеров представляет экзистенциальную угрозу для RSA. Стратегия защиты должна включать использование стойких алгоритмов в гибридных схемах, миграцию на постквантовые стандарты NIST и инвестиции в полное гомоморфное шифрование.
