# Доклад: Классическая криптография и системы шифрования с открытым ключом

## 4. Обратный элемент по сложению

В кольце вычетов по модулю n каждый элемент a имеет обратный по сложению элемент, обозначаемый через (−a). Он определяется как элемент, для которого выполняется равенство a + (−a) = (−a) + a = 0, где 0 — нулевой элемент кольца. Иными словами, прибавление обратного элемента «обнуляет» исходный элемент в данной алгебраической структуре.

В кольце вычетов Zn обратный по сложению элемент вычисляется как −a mod n, что эквивалентно n − a для ненулевого a. Например, в кольце Z7 обратным к 3 будет 4, поскольку 3 + 4 = 7 ≡ 0 (mod 7). Существование обратного по сложению элемента является одной из аксиом кольца — наряду с ассоциативностью сложения, существованием нулевого элемента, ассоциативностью умножения и дистрибутивностью.

## 5. Поля и конечные поля Галуа

Полем называется алгебраическая структура, которая содержит абелеву группу по сложению и группу по умножению, связанные законами дистрибутивности. Иначе говоря, поле — это кольцо, в котором ненулевые элементы образуют коммутативную группу по умножению. Это означает, что для каждого ненулевого элемента существует обратный по умножению, а умножение коммутативно.

Конечным полем называется поле, содержащее конечное число элементов. Конечные поля также называют полями Галуа в честь французского математика Эвариста Галуа (1811–1832), исследовавшего эти структуры. Обозначаются они через GF(q), где q — число элементов поля. Число элементов конечного поля всегда является степенью простого числа: q = p^k, где p — характеристика поля, а k — натуральное число.

## 6. Порядок элемента группы

Пусть G — произвольная группа по умножению. Порядком элемента a группы G, обозначаемым через ordG(a), называется наименьшее натуральное число k такое, что a^k = 1, где 1 — нейтральный элемент группы. Иными словами, порядок элемента — это минимальное число его последовательных умножений на себя, дающее единицу.

Порядком группы называется число её элементов. Связь между порядком элемента и порядком группы устанавливает теорема Лагранжа: порядок любого элемента конечной группы является делителем порядка группы. Доказательство основано на том, что элементы a, a², ..., a^k = 1 образуют подгруппу, а группа разбивается на смежные классы равной мощности.

## Криптография в Новое время

В позднем Средневековье появились полиалфавитные шифры, включая шифр Виженера, который столетиями считался неразрушимым. В XVII–XIX веках возникли механические устройства — дисковые шифры и «цилиндр Джефферсона». Ключевым этапом стало появление электромеханических машин, самая известная из которых — немецкая «Энигма» с системой роторов. Однако работа А. Тьюринга показала, что даже такие системы могут быть взломаны.

## Переход к компьютерной эре

С середины XX века криптография перешла на математические алгоритмы. Симметричные системы использовали один ключ для шифрования и расшифрования. Примеры: DES (56-битный ключ) в США и ГОСТ 28147-89 (256-битный ключ) в СССР. Главный недостаток симметричных систем — проблема распределения ключей, а с ростом вычислительной мощности возникла угроза полного перебора.

## Революция асимметричной криптографии

В 1976 году Диффи и Хеллман предложили обмен ключами по открытому каналу. В 1977 году Ривест, Шамир и Адлеман создали RSA — первый полноценный шифр с открытым ключом, основанный на сложности факторизации. В 1980-е появились эллиптические кривые (ECC), обеспечивающие сопоставимую стойкость при меньшей длине ключа. Асимметричная криптография породила электронную цифровую подпись и стала основой протоколов SSL/TLS.

## Криптография и квантовые технологии

Квантовые компьютеры угрожают классическим алгоритмам. Алгоритм Шора за полиномиальное время решает задачи факторизации и дискретного логарифмирования, что делает RSA и Диффи-Хеллмана уязвимыми. Алгоритм Гровера вдвое снижает стойкость симметричных шифров. В ответ развивается постквантовая криптография: алгоритмы на решётках, кодах, многочленах. В 2024 году NIST утвердил первые постквантовые стандарты — CRYSTALS-Kyber, CRYSTALS-Dilithium, Falcon, SPHINCS+. Параллельно развивается квантовое распределение ключей (QKD).
